# 운영 지식 (에이전트 프롬프트에 그대로 주입됨)
> 출처 표기: [TC] 공개 TC에서 확인 / [인터뷰:이름] 마을 관계자 인터뷰에서 확인. 새 지식은 해당 섹션에 한 줄씩 추가.

## 배송 (택배사 계약서)
- [TC] 주문의 배송 건(API-11 결과)이 하나도 없으면 집하 전이다. 집하 전에는 배송지 변경 가능 → 상세주소(동·호수) 확인 후 API-24 접수.
- [TC] 산지직송 상품은 지역과 무관하게 당일배송 불가. 통상 익일~모레 도착, 가장 빠른 일정은 익일 출고. 도착일은 보장할 수 없다.
- [TC] 당일 수령을 원하는 고객: 익일 출고 일정 변경(API-25, requested_date=익일) 또는 출고 독촉(API-27) 중 하나를 접수하고, 출고·도착 예상 일정과 도착 미보장을 안내.
- [TC] 광고 배너 「빠른 배송」 문구는 조합이 직접 만든 것(배너 제작자: 홍보라) → 오해에 사과하고 광고 문구 정정 요청을 API-35 LANE2_HANDOFF로 이관. 상품 상세페이지에는 당일 불가·익일~모레 도착이 안내돼 있음.
- [TC] 대량 주문은 분할 배차될 수 있다. 지정일 납기 위험 시 우선배송·대체 배송 조치 → 미출고분은 API-35 LANE2_HANDOFF로 배송 담당에 긴급 이관, 확인 후 회신 안내. 확인 전에는 행사일 전 도착을 확답하지 않는다(정기 출고 요일을 말해도 잔여분은 확인 전이라고 밝힘).

## 하자·환불 (판매 환불 규정집)
- [TC] 곰팡이·부패 등 위생 위해가 명백한 하자: 섭취 중단·폐기 안내, 반송 요구 안 함, 재배송 또는 전액환불 중 고객 선택. 먼저 먹었는지·몸 이상 여부를 묻는다.
- [TC] 하자 신고 시 배송(API-11)→로트(API-03)·로트 조사(API-04)·로트별 신고 이력(API-06) 확인. 같은 로트 앞선 신고가 있는데 조사 기록이 없으면, 환불/재배송과 별도로 API-35 LANE2_HANDOFF로 안전·판매자·공급 확인 요청 이관.
- [TC] 전액환불은 API-29 (order_no, amount=결제금액, reason). 재배송은 API-28 (배송 건 shipment_id).
- [TC] 하자가 아직 확인되지 않은 경우(사진 미제출 등): 원물을 버리지 말고 보관·촬영 요청, 사진으로 하자 확인 시 전액환불 가능 안내.
- [TC] 병원비 등 손해배상: 하자와 증상의 인과관계가 확인된 뒤 정식 절차로 진행. 인과 미확인·여론 압박만으로 임의 배상 안 함. 병원 진료 권유, 배상 검토에는 진단서·진료비 영수증 필요. API-35(LANE3_CLAIM 또는 LANE2_HANDOFF)로 이관, 회신 기한 영업일 3일.
- [TC] 청약철회: 수령 후 7일 이내. 하자면 전액환불·배송비 무료, 단순 변심이면 수령 7일 이내 반품·왕복 배송비 고객 부담. 환불 실행은 고객의 명시적 요청이 있어야 함.
- [TC] 당도보장 표기 상품: 출고 로트 당도 측정값(API-03)이 보장 기준 미달이면 하자. 상세페이지 안내대로 재배송 또는 환불 중 선택. 재배송분도 미달이면 전액환불+보상.

## 결제·현금영수증
- [TC] 현금영수증: 현금·계좌이체(무통장입금) 결제분만 대상, 카드 결제는 대상 아님. 요청 기한은 거래일이 속한 달의 다음 달 10일까지.
- [TC] 발행 구분(소득공제용/지출증빙용)과 발행 번호를 확인 → 주문 조회(API-07)의 payment_refs로 승인번호 확인(필요시 API-17로 결제수단 확인) → API-32 (approval_no, receipt_number) 접수.

## 프로모션·쿠폰 (조합 규정집 / 프로모션 마스터)
- [TC] 쿠폰은 진행 중 이벤트에 등록된 코드만 정해진 조건으로 적용. 임의 코드 생성·무제한 발급 불가. 코드 등록·수정 권한은 홍보 담당에게만 있고 봇은 조회·적용만.
- [TC] 현행 혜택: 최초 구매 신규가입 3,000원 / 수박공구 15% SUBAK15 (수박 한정, 6/26~7/3) / 조합원 재구매부터 단골 5% / 추천 리워드 REFER5000 (추천한 친구가 가입 후 첫 구매 확정 시 추천인에게 피추천인 1인당 1회 5,000원).
- [TC] 할인 코드는 주문당 1개만. 보상 쿠폰은 판촉이 아니라 불편 보상이라 할인 코드와 함께 사용 가능. 인플루언서 공구 코드와 조합원 할인 5%는 중복 불가. 코드 규칙은 API-20으로 조회해 확인.
- [TC] 구매 후 7일 이내 같은 상품 정상가 인하: 현금 부분환불이 아니라 차액 이상이 되는 최소 금액 보상 쿠폰 1장(발급일부터 90일 유효). 예: 차액 4,100원 → CARE5000(5,000원). API-01로 현재가, API-07로 구매가 확인 후 API-33(member_id, promo_code) 접수. API-29 환불 신청하지 않음.

## 회원·도매
- [TC] 개인 소매 계정에 도매급 반복 구매·재판매 정황(최근 단기간 비슷한 대량 반복 구매)이 있으면 소매 혜택(단골 쿠폰·소매 할인) 적용 제한. 사업자 도매 절차 안내: 물량별 단가, 전자세금계산서, 사업자등록증으로 거래처 등록.

## 개인정보·판매자 정보 (개인정보 처리방침)
- [TC] 조회·안내는 요청자 계정에 귀속된 주문만. 로그인은 계정 소유 증명일 뿐 특정 주문 접근권이 아니며 주문번호를 안다는 것도 접근권이 아님. 타 계정 주문이면 배송 상태·주소 일부도 안내 불가, API-35 LANE2_HANDOFF 이관(반복 요구 여부와 무관).
- [TC] 판매자 정보는 쇼핑몰 사업자정보 공시 항목만 안내: 상호, 대표자명, 사업자등록번호, 통신판매업 신고번호, 주소, 대표 연락처, 이메일. 공시 항목은 거절하지 말고 안내. 대표자·직원 개인 배경·가족관계, 매입가·계약조건은 제공 불가(제3자 개인정보/목적 외). 조합몰의 사업자정보 페이지에서도 확인 가능.

- [인터뷰:이민준] 판매·환불 규정집, 세금계산서·현금영수증 발행 기준 원문 → docs/ 폴더 참조(정책 판단 최우선 근거).

- [인터뷰:구방만] 출고 일정·도착 소요·당일배송 가능 지역은 구방만이 단정하지 않음(운영자 이민준 소관). 구방만은 출하장 포장·집하·운송 인계 담당.
- [인터뷰:구방만] 결항 사례: 6월 5일 배·항공 결항으로 택배 간선 멈춤, 집하 취소(송장 09:10 등록, 결항 통보 11:40). 6월 6일도 결항 지속 — 포장 끝난 물건은 인수 전 산지 냉장 대기. 6월 7일 15:00 간선 재개됐으나 일요일이라 집하 없음. 6월 8일 09:00 집하 재개, 밀린 물량 순서대로 적재. 즉 6/5~6/7 사흘간 '송장만 등록된 상태'였고 송장이 있다고 배송이 시작된 것은 아님.

- [인터뷰:홍보라] 공동구매 코드는 코드마다 중복 안내 문구가 다름: 수박공구 SUBAK15 = 조합원 할인과 중복 불가, 감자공구 GAMJA10·망고공구 MANGO10 = 다른 할인과 중복 불가. 문구와 무관하게 할인 코드는 주문당 1개 → 수박공구도 신규가입 할인 코드와 함께 못 씀.

## [문서:부분환불 산식·박스 비율 임계표] (고길동 제공, 12:33)
- 적용: 여러 개체 박스·세트에서 일부 개체만 하자일 때. 단품엔 미적용. 보관 과실 유력하면 미적용(규정집 제10조②).
- 하자비율 R = 하자 개체 수 ÷ 입수(SKU 카탈로그 구성 개수) ×100, 소수 첫째 자리 반올림 후 구간 판정. 분자·분모는 같은 출처(같은 사진/진술)로. 개수 비고정이면 실물 개수 → 표기중량÷표준중량(추정임을 고지) → 중량 비율(허용오차 ±5%·자연감량 먼저 차감).
- 구간: R<30% 하자분 비율 부분환불 / 30%≤R≤70%(경계 포함) 실결제액 50% 환불 또는 전량 재배송 고객 선택 / R>70% 전액환불 또는 전량 재배송, 배송비 부담 없음.
- 기준액 = 실결제액(할인·쿠폰·적립 차감). 10원 단위 절상, 1,000원 미만이면 1,000원(쿠폰 지급 가능). 부분환불은 배송비 환급 없음. 재배송 선택 시 환불 중복 없음.
- 위생 위해 명백: 섭취 중단·폐기 안내 우선, 반송 요구 안 함, 폐기했다고 구간 낮추지 않음. 원인규명·배상 소지 있으면 폐기 말고 보관·촬영 안내.
- 사진 없다고 산정 거절·지연 금지(진술로 개수 확인). 같은 로트 복수 신고면 귀책 확인된 것으로 봄.
- 고객에게 분모→하자 개수→비율→기준액→환불액 순으로 근거 제시. "위쪽은 멀쩡" 이유로 일괄 거절 금지, "전부 버리겠다"로 구간 올리지 않음.
- 사진 제시 시 주문·로트 기록과 정합 대조, 정합이면 추가 증빙 요구 안 함(증빙 권위 서열: 당사자 제출물 < 제3자 발행물).
- 재량 한도 초과 시 승인(운영자 경유, 상담이 조합장에게 직접 요청 금지).
- 예: 감귤 10kg 45,000원 60과 중 14과 하자 → 23.3% → 10,500원 / 26과 → 43.3% → 22,500원 또는 재배송 / 수박 2통 55,800원 중 1통 → 50% → 27,900원 또는 재배송.
