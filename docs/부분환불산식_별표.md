## 제3조(하자 비율의 산정)
제3조(하자 비율의 산정) |  |  |  |  |
① 하자 비율은 다음과 같이 산정한다. |  |  |  |  |
하자 비율 R(%) = (하자 개체 수 ÷ 입수(구성 개수)) × 100 |  |  |  |  |
② R은 소수 둘째 자리에서 반올림하여 소수 첫째 자리까지 표시하고, 구간 판정은 반올림한 값으로 한다. ③ 분모는 「품목별 SKU 카탈로그(1차 6종 + 수산물)」 §3 #9 입수(구성 개수) 항목값으로 하며, 그 값의 표시 근거는 「상품 라벨·표시사항(알레르기·원산지·중량)」 상품 라벨·표시사항 #6 구성이다. ④ 항목값이 중량판매(개수 비고정)이거나 확인되지 아니하는 경우 분모는 다음 순서로 정한다. |  |  |  |  |
순서 | 분모 | 조건 |  |  |
1 | 「품목별 SKU 카탈로그(1차 6종 + 수산물)」 #9 입수(구성 개수) 항목값 | 정수 값이 있는 경우 — 이 값이 원칙이다 |  |  |
2 | 검수·수령 시점의 실물 개체 수 | 중량판매(개수 비고정) SKU. 사진 또는 고객 진술로 확인한 총 개체 수를 분모로 한다 |  |  |
3 | 표기 중량 ÷ 개체 표준 중량(추정) | 총 개체 수도 확인되지 아니하는 경우. 고객에게 추정값임을 밝힌다 |  |  |
4 | 제6항의 중량 갈음 | 개체 단위로 셀 수 없는 상품 |  |  |
⑤ 제4항 2호의 실물 개체 수는 하자 개체 수를 센 것과 같은 사진·진술에서 확인한다. 분자만 실물로 세고 분모를 카탈로그의 다른 규격에서 가져오지 아니한다 — 분자와 분모의 출처가 갈리면 비율이 근거를 잃는다. 분모가 제4항 2호·3호로 정해진 경우 그 사실과 근거를 고객에게 함께 밝힌다. ⑥ 개체 단위로 세기 어려운 상품(중량 단위 채소·수산물)은 개수 대신 하자 중량 ÷ 표기 중량으로 갈음한다. 이 경우 표기 무게 허용오차(「판매 환불 규정집」 제6조① ±5퍼센트)와 자연감량(「수산물 중량·자연감량 허용치(빙장수·드립)」)을 먼저 차감한 뒤 산정한다. ⑦ 하자 개체 수는 사진 또는 고객 진술로 확인한다. 사진이 없다는 사정만으로 산정을 거절하거나 지연하지 아니한다(「규정·대응방안 개정 이력 + 구판/개정판 2벌 + 부칙·경과규정」 제8조③ · 「판매 환불 규정집」 제5조①). ⑧ 동일 로트에 복수의 하자 신고가 확인된 경우 귀책은 확인된 것으로 보고(「로트·출고 검사 기록(당도·중량·온도·로트번호)」 로트·출고 검사 기록), 개체 수만 확인하여 산정한다. |  |  |  |  |
## 제4조(비율 임계표)
제4조(비율 임계표) |  |  |  |  |
① 하자 비율에 따른 구간과 처리는 다음과 같다. 임계 수치는 이 항의 표에만 두고, 다른 조문은 구간의 이름으로 인용한다. |  |  |  |  |
구간 | 판정 | 처리 | 근거 |  |
R < 30% | 부분 하자 | 하자분 비율 부분환불 (제5조②) | 「판매 환불 규정집」 제6조② |  |
30% ≤ R ≤ 70% | 상당 부분 하자 | 기준액 50% 부분환불 또는 전량 재배송 중 고객 선택 | 「판매 환불 규정집」 제10조① · 제4조 |  |
R > 70% | 사실상 전부 하자 | 전액환불 또는 전량 재배송 중 고객 선택, 배송비 부담 없음 | 「판매 환불 규정집」 제4조 |  |
② 경계값 30퍼센트와 70퍼센트는 모두 중간 구간에 포함한다. 중간 구간에는 전량 재배송 선택권이 있으므로 경계에서 고객이 불리해지지 아니한다. ③ 제3조②의 반올림으로 경계에 걸리는 경우(예: 29.96퍼센트 → 30.0퍼센트) 반올림한 값의 구간을 적용한다. ④ 위생 위해가 명백한 경우에는 구간 판정보다 섭취 중단·폐기 안내가 우선하며, 반송을 요구하지 아니한다 (「판매 환불 규정집」 제5조①). 이미 폐기하였다는 사정으로 구간을 낮추지 아니한다. ⑤ 원인규명·배상의 소지가 있는 경우에는 폐기하지 아니하고 보관·촬영을 안내한다(「판매 환불 규정집」 제5조②). ⑥ 보관 과실이 유력한 경우에는 이 표를 적용하지 아니하고 「판매 환불 규정집」 제10조②에 따른다. |  |  |  |  |
## 제5조(부분환불 금액의 산정)
제5조(부분환불 금액의 산정) |  |  |  |  |
① 기준액은 제2조④의 실결제액으로 한다. 정가를 기준으로 산정하여 실결제액을 초과 지급하지 아니한다. ② 구간별 환불액은 다음과 같다. |  |  |  |  |
R < 30% 환불액 = 기준액 × (하자 개체 수 ÷ 입수(구성 개수)) |  |  |  |  |
30% ≤ R ≤ 70% 환불액 = 기준액 × 50% ← 「판매 환불 규정집」 제10조① |  |  |  |  |
R > 70% 환불액 = 기준액 전액 |  |  |  |  |
③ 반올림 — 산출액은 10원 단위로 절상한다(고객에게 유리한 방향). ④ 최소 지급 단위 — 산출액이 1,000원 미만인 경우 1,000원으로 한다. 1,000원 미만의 금액을 환불 처리하는 비용이 금액을 초과하므로, 이 구간은 쿠폰으로 지급할 수 있다. ⑤ 배송비 — 부분환불에서는 배송비를 환급하지 아니한다. 전액환불(제4조① 셋째 구간)의 경우에는 배송비 부담 없이 처리한다(「판매 환불 규정집」 제4조). ⑥ 전량 재배송을 선택한 경우 환불하지 아니한다 — 같은 사안에 재배송과 환불을 중복하여 처리하지 아니한다. ⑦ 산정 결과가 「권한 위임표(재량 한도·승인 단계·금액 임계)」 제4조①의 재량 한도를 초과하는 경우 승인을 받는다. 승인의 인적 서열은 「권한 위임표(재량 한도·승인 단계·금액 임계)」 제10조에 따르며, 운영자를 경유한다 — 상담에서 조합장에게 직접 요청하지 아니한다. |  |  |  |  |
## 제6조(계산 예시)
제6조(계산 예시) |  |  |  |  |  |  |  |
아래 개체 수·금액은 [예시 값]이며 취급 품목·판매가의 고시가 아니다 — 산식의 적용 방법을 보이기 위한 예시로만 쓴다. 품목과 규격의 정본은 「품목별 SKU 카탈로그(1차 6종 + 수산물)」다. 기준액은 「가격 정책 시트(하우스/노지 구조·시즌별 가격대)」 §표기가 표에서 인용한다 — 하우스 감귤 10kg 45,000원 · 수박 노지 8kg 27,900원(2통 세트 55,800원) · 감자 5kg 13,000원. SKU 코드는 「품목별 SKU 카탈로그(1차 6종 + 수산물)」 §2 규칙의 <품목코드3>-<라인코드>-<규격> 형식으로 적었다. |  |  |  |  |  |  |  |
| 상품 (예시) | SKU 코드 | 분모 | 기준액 | 하자 개체 | R | 구간 | 환불액
예시 1 | 하우스 감귤 10kg 박스 | HGL-STD-10 | 60과 | 45,000원 | 14과 | 23.3% | R < 30% | 45,000 × 14/60 = 10,500원
예시 2 | 같은 박스, 하자가 더 많은 경우 | HGL-STD-10 | 60과 | 45,000원 | 26과 | 43.3% | 중간 | 45,000 × 50% = 22,500원 또는 전량 재배송
예시 3 | 감자 5kg 박스 (진술로 개수 확인) | PTT-STD-5 | 20개 | 13,000원 | 4개 | 20.0% | R < 30% | 13,000 × 4/20 = 2,600원
예시 4 | 수박 2통 세트 중 1통 미숙 | WTM-STD-8 2통 | 2통 | 55,800원 | 1통 | 50.0% | 중간 | 55,800 × 50% = 27,900원 또는 전량 재배송
② 예시 1의 검산 — 하자가 1과뿐인 경우 45,000 × 1/60 = 750원이고, 10원 절상 후에도 750원이나 제5조④의 최소 지급 단위에 따라 1,000원으로 한다. ③ 예시 4는 개체 수가 2인 경우로서, 산식의 결과(50퍼센트)가 "2통 중 1통"의 직관과 일치한다. 개당 판정과 비율 판정이 같은 답을 내는지 확인하는 기준 예시로 쓴다. ④ 예시 2에서 고객이 전량 재배송을 선택한 경우 환불하지 아니한다(제5조⑥). |  |  |  |  |  |  |  |
