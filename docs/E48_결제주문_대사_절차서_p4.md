# E48_결제주문_대사_절차서_p4 (이미지 전사)

문서 보기 / 결제·주문 대사 절차

M-01 주문 유실을 M-08 중복 결제로 판정하여 환불만 처리하지 않도록 유의한다. 주문이 조회되지 않는다는 사실만으로 중복 결제로 확정하지 않으며, 유실된 주문의 복구 가능 여부를 확인한다. **중복 결제는 결제 승인이 2건일 때만 성립한다.**

## 4. 주문 복구 및 환불 기준

M-01이 확정된 경우 유효한 결제와 고객의 구매 의사에 따라 **주문 복구**를 원칙으로 한다.

| 조건 | 처리 |
|---|---|
| 상품 확보 가능 + 출하 가능 | **주문 복구** — 결제 내역을 원본으로 주문을 재생성하고 정상 출하 |
| 품절·시즌 종료로 출하 불가 | **미배송분 환불** (전액) |
| 지연으로 고객이 더는 원하지 않음 | **미배송분 환불** — 고객 의사를 우선한다 |
| 일부만 출하 가능 | 출하분 유지 + **미배송분만 환불** (부분) |

**환불 기준액도 실결제액**이다(§1과 같은 기준). 복구 시에는 **추가 결제를 요구하지 않는다** — 가격이 그 사이 올랐어도 결제된 금액대로 출하한다.

주문 유실에 대한 처리 책임은 조합에 있다. 기존 결제에 대한 복구 또는 환불 처리를 완료하여야 하며, 고객에게 재주문만 요청하고 종결하지 않는다.

## 5. 대사 키와 판정값

| | 값 |
|---|---|
| 대사 키 | 카드 **뒷 4자리** · 승인번호 · 금액 · 승인 시각 — 전체 번호·유효기간·CVC는 대사 키가 아니다 |
| 뒷 4자리 확인 방식 | **고객이 제시한 값과 대조**한다. 원장 값을 먼저 읽어 주는 필드가 아니다 |

결제·주문 대사 절차 — 4 / 6
