## 2. 물량별 단가
2. 물량별 단가 |  |  |  |  |
별도의 도매 가격표를 두지 않는다. 기준은 소매 표기가(「가격 정책 시트(하우스/노지 구조·시즌별 가격대)」 표기가 표의 정상가 · 시즌 성기 기준)이고, 아래 할인율을 그 값에 적용한 것이 도매 단가다. 도매용 기준가를 따로 만들면 같은 품목의 값이 두 벌이 되어 한쪽만 갱신되는 일이 생긴다. |  |  |  |  |
| 산식 |  |  |  |
도매 단가 | 소매 표기가(규격 상자 단위) × 등급 계수(§3) × (1 − 물량 할인율) |  |  |  |
시즌 위치 | 소매와 같은 계수를 쓴다 (「가격 정책 시트(하우스/노지 구조·시즌별 가격대)」 초기 +20% / 성기 기준 / 말기 −20%) — 도매만 따로 움직이지 않는다 |  |  |  |
규격 단위 | 상자 규격은 「품목별 SKU 카탈로그(1차 6종 + 수산물)」 SKU 규격을 그대로 쓴다. 중량 구간은 상자 규격 × 상자 수로 환산한다 |  |  |  |
구간 | 1회 주문 총 중량 | 할인 |  |  |
1구간 | 100kg 이상 | 10% |  |  |
2구간 | 500kg 이상 | 15% |  |  |
3구간 | 1t 이상 | 20% |  |  |
| 규약 |  |  |  |
산정 단위 | 1회 주문 총 중량 (회차별 합산, 누적 아님) |  |  |  |
품목 혼합 | 여러 품목을 한 주문에 담으면 총 중량으로 합산해 구간을 잡는다 |  |  |  |
등급 혼합 | 등급이 갈려도 총 중량으로 합산한다 — §4 |  |  |  |
구간 밖 | 3구간을 넘는 대량의 추가 할인은 조합장 승인 사안 |  |  |  |
소매 프로모션 | 중복 적용하지 아니한다 — 도매 단가와 소매 쿠폰은 배타 (§7) |  |  |  |

## 3. 등급
3. 등급 |  |  |  |  |
등급 | 기준 | 용도 예시 | 기준가 계수 |  |
정상품 | 선별 기준 통과 (당도·규격) | 판매·선물·촬영 | 100% |  |
B급 · 못난이 | 외관·규격 미달, 식용 적합 | 가공·급식·사료·먹이 | 60% |  |
등급 정의의 정본은 「품목별 SKU 카탈로그(1차 6종 + 수산물)」이고 B급 판매 자체의 근거는 「조합 규정집」 제20조이다 — 이 문서는 계수와 용도만 정한다. |  |  |  |  |
B급은 하자품이 아니다 — 외관 등급이 낮을 뿐 식용에 문제가 없다. 반대로 B급으로 판매한 건에 대해 외관 사유의 하자 접수는 성립하지 아니한다(§7). |  |  |  |  |
## 4. 등급 혼합 분배
4. 등급 혼합 분배 — 주문 내 용도별 등급 구분 |  |  |  |  |
한 거래처의 한 주문 안에서 용도별로 등급·단가를 분리해 견적할 수 있다. 전량에 동일 등급을 일괄 적용하지 아니한다. |  |  |  |  |
라인 항목 | 내용 |  |  |  |
라인번호 | 견적 내 순번 |  |  |  |
품목 | 취급 품목 중 하나 — 수박 WTM · 하우스감귤 HGL · 노지감귤 NGL · 만감류 MDR · 애플망고 MNG · 멜론 MLN · 감자 PTT · 고구마 SWP · 참다래 KIW · 절임배추 SLC (품목·규격 코드 정본은 「품목별 SKU 카탈로그(1차 6종 + 수산물)」) |  |  |  |
등급 | 정상품 / B급 (§3). 절임배추는 정상품만 — 주문받아 제작하는 품목이라 외관 등급이 갈리지 않는다 |  |  |  |
용도 | 거래처가 밝힌 용도 (급여·가공·촬영·전시 등) |  |  |  |
수량 · 중량 | 라인별 |  |  |  |
단가 | 기준가 × 등급 계수 × (1 − 물량 할인율) |  |  |  |
소계 | 단가 × 수량 |  |  |  |
물량 할인은 라인별이 아니라 주문 총 중량으로 잡는다 — 라인마다 따로 재면 등급을 나눌수록 할인이 줄어들어, 정직하게 용도를 밝힌 거래처가 불리해진다. |  |  |  |  |
예시 — 수박 WTM 8kg 상자, 한 주문 2,000kg |  |  |  |  |
라인 | 등급 | 용도 | 중량 | 단가 근거 |
1 | B급 | 급여용 | 1,600kg (8kg × 200상자) | 소매 표기가 × 60% × (1 − 20%) |
2 | 정상품 | 촬영·홍보용 | 400kg (8kg × 50상자) | 소매 표기가 × 100% × (1 − 20%) |
두 라인의 합계 2,000kg이 3구간(1t 이상)에 들어가므로 할인율 20%가 두 줄에 같이 붙는다. 다만 2,000kg은 §5 일 출하 출하 가능량와 같은 값이라 하루에 나갈 수 있는 상한이고, 여기서 한 상자라도 늘면 분할 출하 일정이 된다. |  |  |  |  |
전량을 한 등급으로 견적하지 아니한다. 전량 B급이면 촬영용 몫을 놓치고, 전량 정가면 급여용에 값을 더 받는다. 용도를 먼저 확인하고 라인을 나눈다. |  |  |  |  |
